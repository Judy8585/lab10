# 2026 Winter Olympics Schedule Analysis

This project analyzes the 2026 Winter Olympics schedule using the TidyTuesday dataset.

## Questions

- Which venues host the most events?
- Which sport disciplines have the most scheduled events?

## Venue Analysis

Cortina Curling Olympic Stadium hosts the most events, with 436 scheduled events. Livigno Snow Park and Cortina Sliding Centre follow with 297 and 290 events.

See `venue_analysis.ipynb` for the full analysis.
